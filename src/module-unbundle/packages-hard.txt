# Hard variant removes these too: phone basics, Google system components and Pixel extras. Second column is a role
# the app may be the only one for, it's kept until another app for it is installed (keyboards only when enabled).
#
# Each Google app on Android 15 emulator image was removed one by one and checked (boot, crashes, ANRs, Settings
# pages and entries, share sheet, file/sound pickers, camera, dialer, home, network, keyboard). Kept on purpose:
# - Bootloop: GoogleExtShared (com.google.android.ext.shared), ModuleMetadata, Package Installer
# - Network Stack: no network at all
# - DocumentsUI: no file picker, apps can't open files
# - Sound picker: no ringtone and alarm sound picker
# - Settings search (com.google.android.settings.intelligence): search bar disappears from Settings
# - Captive portal login: hotel/airport Wi-Fi login stops working
# - ConfigUpdater (security config updates), Emergency Info, Satellite SOS: no visible change, but needed
# - Setup Wizard (breaks account sync), Device Health Services (breaks battery settings), carrier and IMS services
#   (calls): not on emulator, kept after reports
# - com.android.bluetooth: only a migration stub on Android 15, but Bluetooth itself on Android 11-12
# - Overlays, APEX modules (can't be removed) and Noogle microG ones
# Without enabled keyboard Android switches to Speech Services voice input (no typing) and stays on it even after
# Gboard comes back, so keyboard check counts only enabled ones.
